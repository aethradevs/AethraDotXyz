# AETHRA Website

Static, responsive four-page AETHRA website.

## Pages
- `index.html` — Home
- `network.html` — Network
- `architecture.html` — Architecture
- `about.html` — About

## Deployment
Upload all files and the `assets` directory to a GitHub repository. In GitHub Settings → Pages, select Deploy from a branch, `main`, `/ (root)`.

## Assets
- `assets/aethra-logo.png`: extracted from the supplied original AETHRA logo.
- `assets/cityscape.jpg`: AETHRA metropolitan artwork created in this conversation.

No external JavaScript frameworks or backend are required. Google Fonts is optional; system font fallbacks are provided.

All product descriptions are conceptual, not assertions of a live deployed AI service.
